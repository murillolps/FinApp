FinApp

Aplicativo web para controle financeiro pessoal, com backend em Node.js/Express, frontend em React/Vite e banco de dados MySQL. MVP publicado em produção.

🔗 Acesse: https://finapp-flame-nine.vercel.app (o backend roda no plano free do Render e hiberna após 15 min sem uso — a primeira requisição pode levar ~1 minuto pra responder)

Funcionalidades
Cadastro e login de usuário (autenticação via JWT)
Registro de lançamentos financeiros (entradas e saídas)
Definição de orçamento e metas financeiras
Dashboard com gráficos para visualização dos dados
Stack

Frontend: React, Vite, React Router, Tailwind CSS Backend: Node.js, Express, JWT Banco de dados: MySQL (Clever Cloud) Deploy: Vercel (frontend) + Render (backend)
